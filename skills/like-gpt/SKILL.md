`$ARGUMENTS` 의 글을 **한 번에 읽히는 문장**으로 다듬는다. 내용은 바꾸지 않는다.

`$ARGUMENTS` 가 비어 있으면 무엇을 다듬을지 먼저 묻는다 — 파일 경로 · 붙여넣은 글 · 방금 쓴 문서 중 하나.

## 쓰는 자리 · 안 쓰는 자리

| | |
|---|---|
| **쓴다** | 규약 문서 · 스킬 본문 · 스펙 · PR 본문 · 리뷰 코멘트 — **한 번에 정확히 읽혀야** 하는 글 |
| **안 쓴다** | 에세이 · 회고 · About · 짧은 평 · UI 문자열 — `writing-voice` 의 Voice A/B/C 가 정본이다 |

**경계가 여기다.** 이 스킬은 문장을 길고 완전하게 만든다. 그건 Voice A 의 짧은 문장과 대구 펀치라인을 죽인다. 에세이에 걸면 힘이 빠진다.

## 일곱 가지 변환

| | before | after |
|---|---|---|
| **생략 복원** — 빠진 성분을 되살린다 | "게이트가 ~면" · "앞을 잊기" | "~는 원칙이라면" · "앞선 내용을 잊기" |
| **축약 해제** — 구어 축약을 완전형으로 | "안 끝난다" · "검증 안 된" · "그건" | "끝나지 않는다" · "검증되지 않은" · "그것은" |
| **비유 직설화** — 은유를 실제 동작으로 | "종이로 못 가릴 때" · "다음 세션의 입구" | "문서만으로 결정할 수 없을 때" · "이 둘을 기준으로 이어간다" |
| **구어 동사 → 표준어** | "짠다" · "심문한다" · "벌어진다" | "구현한다" · "질문해 도출한다" · "확장된다" |
| **형식명사 → 실질명사** | "마지막 것" · "그 둘" | "마지막 원칙" · "앵커와 `[x]`" |
| **명사 서술 → 동사 서술** | "입구가 그 둘이다" | "이 둘을 기준으로 작업을 이어간다" |
| **수사 표기** — 고유어 수사를 단위와 함께 | "워크스페이스 넷 이상" | "네 개 이상의 워크스페이스" |

**볼드를 줄인다.** 한 문단에 볼드가 셋을 넘으면 강조가 아니라 배경이 된다. 정말 남길 한 줄만 남긴다.

**조사는 붙여 쓴다.** `Plan이` · `Spec에` · `[x]를`. 코드 식별자 뒤라도 붙인다.

## 건드리지 않는 것

- **대시(`—`) 부연** — 이 하네스의 문체다. 문장마다 붙지만 않으면 유지한다
- **표 · 불릿 · 헤딩** — 마크다운 구조는 그대로 둔다. 표를 산문으로 풀지 않는다
- **코드 · 경로 · 명령 · 수치 · 고유명사** — 백틱 안은 한 글자도 건드리지 않는다
- **인용 블록** — 남의 말이다

## writing-voice 와의 관계

`writing-voice` §6「KO — AI 가 쓴 티」는 **빼기**다. 헤지 · 결산 접속사 · 번역투를 걷어낸다.
이 스킬은 **풀기**다. 생략된 성분을 되살리고 압축을 편다.

방향이 반대라 순서가 있다. **§6 을 먼저 돌리고 like-gpt 를 나중에 돌린다.** 지문을 안 걷은 채로 풀면 헤지까지 같이 길어진다.

풀다가 헤지가 생기면 실패다 — "~할 수 없을 때"는 되지만 "~할 수 없을 가능성이 있을 때"는 안 된다.

## 절차

1. **as-is / to-be 를 나란히 낸다.** 파일에 곧장 쓰지 않는다
2. 문단이 셋을 넘으면 문단 단위로 끊어 보여준다 — 통짜 diff 는 검토가 안 된다
3. **승인 후** 파일에 반영한다
4. 바꾼 축을 한 줄로 보고한다 — "생략 복원 4 · 축약 해제 6 · 비유 2"

## 판정

1. **내용이 바뀌지 않았는가** — 문장이 길어진 만큼 새 주장이 들어가지 않았는가
2. 원문에 없던 비유 · 상투구를 **새로 심지 않았는가**
3. 절반 이상을 고치고 있지 않은가 — 그건 윤문이 아니라 다시 쓰는 것이다. 멈추고 묻는다
4. 에세이에 걸고 있지 않은가 (「쓰는 자리」)
