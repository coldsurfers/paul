# 스템에서 믹스·마스터링

**나는 소리를 못 듣는다. 그래서 판단하지 않고 측정한다 — 그리고 고르는 건 사람이 한다.**

이 둘을 지키면 된다. 숫자로 문제를 찾아내고, 해결 후보를 **소리로 만들어** 사람에게 고르게 한다.
내가 "이게 맞다"고 단정하는 순간 틀린다 (아래 함정 1번이 실제 사례다).

## 절차

```
1. 형식 확인   ffprobe — 샘플레이트 · 비트 · 길이. 길이가 제각각이면 섹션별 편곡이다
2. 위생 검사   클리핑 · 피크 · 크레스트. 깨진 스템이 있으면 여기서 멈추고 재추출 요구
3. 편곡 지도   구간별 RMS 표 — 누가 언제 연주하나. 이게 모든 판단의 바닥
4. 밸런스      "울릴 때" 기준 구간별 비교. 통합 LUFS 로 비교하지 말 것 (함정 1)
5. 공간 감사   LRA · 구간 RMS 편차 · 구간 상관도 편차 · 대역 S−M 네 숫자 (아래 절).
               임계 아래면 마스터링으로 못 고친다 — 믹스 단으로 돌려보낸다
6. 후보 렌더   2~4안을 만들어 전부 같은 LUFS 로 정규화해 들려준다 → 사람이 고른다
7. 경계 오토메이션  섹션 경계를 silencedetect 로 찍고 그 자리에서만 게인을 바꾼다
8. 마스터링    EQ → 글루 컴프 → 리미터. 배포본은 −10 LUFS · TP −1.0 dBTP 하나.
               비교 청취용(−12/−14)이 필요하면 compare/ 하위로 내린다 (함정 9)
9. 배포 게이트  올리기 직전 I·TP 를 다시 찍는다 — −10±1 LUFS · TP ≤ −1.0 dBTP
```

**2번에서 깨진 게 나오면 3번 이후는 전부 무의미하다.** 클리핑된 스템 위에서 계산한 밸런스는
왜곡 위에 쌓은 것이다. 전 채널 −6 dB 재추출을 요구하는 게 정답 — 실측으로 기타 크레스트가
14~16 dB → 21~24 dB 로 회복됐다. 클리핑이 트랜지언트를 7 dB 먹고 있었다.

## 측정 레시피

셸은 **bash 로 강제**한다 (함정 3).

```bash
# 라우드니스 — 요약이 stderr 라 -v error 쓰면 사라진다
ffmpeg -hide_banner -nostats -i "$f" -filter_complex "ebur128=peak=true:framelog=quiet" -f null - 2>&1 \
 | sed -n '/Integrated loudness/,$p' | grep -E "I:|LRA:|Peak:"

# 피크 · RMS · 클리핑  (크레스트 = Peak − RMS)
ffmpeg -hide_banner -nostats -i "$f" -af "astats=metadata=0" -f null - 2>&1 | sed -n '/Overall/,$p'
#   Peak level dB 가 0.00 이고 Abs Peak count 가 수천이면 하드 클리핑
#   Abs Peak count == 전체 샘플 수면 클리핑이 아니라 무음이다 (함정 2)

# 대역 에너지 — 12 dB/oct 이 필요하면 필터를 두 번 건다
ffmpeg ... -af "highpass=f=$LO:poles=2,highpass=f=$LO:poles=2,lowpass=f=$HI:poles=2,lowpass=f=$HI:poles=2,astats=metadata=0"

# 스테레오 폭 · 모노 호환
#   상관도: aphasemeter + ametadata 평균     1=모노 · 0=무상관 · 음수=역위상
#   모노손실: 스테레오 LUFS − 모노합 LUFS    −3 dB 넘으면 위험
ffmpeg ... -filter_complex "pan=stereo|c0=0.5*c0+0.5*c1|c1=0.5*c0+0.5*c1,ebur128=framelog=quiet"

# 섹션 경계 — 오토메이션 시점의 정본
ffmpeg -hide_banner -nostats -i "$f" -af "silencedetect=noise=-55dB:d=0.8" -f null - 2>&1 \
 | grep -oE "silence_(start|end): [0-9.]+"

# 구간 게인 오토메이션 — 누적 piecewise linear
volume=eval=frame:volume='pow(10\,(G0 + (G1-G0)*clip((t-T1)/R\,0\,1) + (G2-G1)*clip((t-T2)/R\,0\,1))/20)'
```

편곡 지도는 20초 창 RMS 표로 그린다. `---`(무음) · 숫자(RMS) · `★`(클리핑) 세 기호면 충분하고,
이 표 하나가 "왜 이 구간만 이상한가"의 답을 거의 다 갖고 있다.

## 공간 감사 — "밋밋하다"를 네 숫자로 가른다

"공간감이 없다"는 보고는 **폭 · 대비 · 톤** 셋 중 어디인지부터 갈라야 한다. 넓히는 건 대부분 오답이다.

| 지표 | 측정 | 건강 범위 | 아래면 |
| --- | --- | --- | --- |
| LRA | `ebur128` | 3 LU ↑ | **< 1 LU** = 곡 전체가 상수 음량 |
| 구간 RMS 편차 | 20초 창 표의 max−min | 3 dB ↑ | **< 1 dB** = 섹션이 죽어 있음 |
| 구간 상관도 편차 | 30초 창 `aphasemeter` max−min | 0.2 ↑ | **< 0.15** = 폭도 상수 |
| 대역 S−M | M/S 분리 후 대역 RMS 차 | 저역 −12↓ · 중고역 −4~−7 | 이 범위면 **넓히지 않는다** |

```bash
# Mid / Side 분리 — pan 문법 주의 (함정 8)
mid='pan=mono|c0=0.5*c0+0.5*c1'
side='pan=mono|c0=0.5*c0-0.5*c1'
```

앞 셋이 전부 임계 아래면 톤을 아무리 손봐도 밋밋하다. **마스터링이 아니라 믹스 · 편곡의 문제**이므로 그대로 보고하고 멈춘다.

**Match EQ** 는 이 표의 어느 칸도 아니다 — *톤* 축이다. `firequalizer` 의 `gain_entry` 로 레퍼런스와의 대역 차를 걸 수 있고, 레퍼런스는 **같은 장르 · 편성**으로 고른다. 1/3 옥타브 스무딩 + **±4 dB 클램프**(넘으면 레퍼런스의 편곡까지 흉내 내 이상해진다), 적용 후 재측정. LRA 가 낮은 채로 톤만 맞추면 **"기성곡 톤인데 여전히 밋밋함"** 이 된다.

## 함정

**1. 통합 LUFS 로 드럼과 지속음을 맞추지 않는다.** 드럼은 크레스트가 28 dB라 LUFS 가 실제보다
작게 읽는다. 그 수치에 맞춰 올리면 드럼만 튀어나온다. **실제로 이 실수를 했고 사용자가
"드럼소리만 엄청 크다"고 잡아냈다.** 비교는 *구간별·울릴 때* RMS 로 한다.

**2. `Abs Peak count == 전체 샘플 수` 는 무음이다.** 디지털 무음에선 모든 샘플이 최댓값(0)이라
클리핑 지표가 만점으로 나온다. Peak level dB 를 같이 보고 판정한다.

**3. zsh 는 `set -- $b` 로 워드 스플리팅을 안 한다.** 필터 인자가 통째로 `$1` 에 들어가 `$2` 가 비고,
ffmpeg 이 조용히 실패해 `0.0` 표가 나온다. 루프는 `bash -c` 로 감싼다.

**4. 하드 패닝이 스테레오 스템을 오히려 좁힌다.** 앰프 시뮬 스템은 이미 벌어져 있어서(상관도 0.2대)
반대 채널을 깎으면 스템 고유의 폭이 죽는다. 실측: 치우침 65% → 상관도 0.41, 85% → **0.51(좁아짐)**,
65%+사이드확장 → **0.26(가장 넓음)**. 넓히려면 `extrastereo` 같은 M/S 확장을 쓴다.

**5. 후보는 반드시 같은 LUFS 로 맞춰 들려준다.** 안 그러면 큰 게 좋게 들린다. 렌더 → 측정 →
`volume` 으로 보정 → 리미터 안전장치 순서.

**6. 오토메이션 브레이크포인트는 측정해서 잡는다.** 20초 창 분석으로 어림잡으면 3~5초씩 어긋나고,
곡이 진행 중인데 게인이 움직여서 **들린다.** `silencedetect` 로 리전 경계를 찍고 그 자리에
0.25초 램프로 바꾼다 — 악기 교체에 묻힌다.

**7. 잔향 꼬리는 만들 수 없다.** 끝이 뚝 끊기면 `afir` 로 인공 꼬리를 붙이려 해도 출력이 입력
길이를 안 넘어 실패한다. DAW 에서 **바운스 종료를 마지막 음 + 8초**로 잡아 재추출받는 게 유일한 답.

**8. `pan` 필터에서 `c1=0` 은 문법 오류다.** 채널을 죽이려면 `c1=0*c0`.

**9. 스트리밍 타깃(−14)을 파일에 미리 깎아 넣지 않는다.** −14 는 *노멀라이징이 켜졌을 때
도달하는 재생 값*이지 업로드 파일의 타깃이 아니다. 켜져 있으면 플랫폼이 알아서 내리므로
−10 을 올려도 결과가 같고, 꺼져 있거나 Bandcamp·다운로드면 파일값이 그대로 나가
**혼자 5~6 dB 작게 들린다.** 실제로 −14 를 제출했고 "Spotify 에서만 작다, Bandcamp 는
괜찮다"로 드러났다 — 스펙트럼은 정상이었고 순수한 레벨 문제였다.
단 이 이득은 *같은 마스터의 게인 차이*일 때만 공짜다. −8 로 밀려고 리미터를 더 조이면
그 왜곡은 노멀라이징이 되돌려주지 못한다. LRA 가 이미 1 LU 아래면 더 올리지 않는다.

**10. 섹션에 악기가 들어올 때 기존 트랙을 내려 총합을 맞추면 대비가 0 이 된다.** 실측: Verse 스템이
들어오는 40초 · 100초에 Chorus 쌍이 정확히 −6 dB 내려가, 최종 마스터 RMS 가 0~160초 내내
**−13.9 ± 0.2 dB** 로 불변이었다(LRA 0.6 LU). 섹션은 편곡에 실재하는데 청자에게는 아무 일도
일어나지 않는다. 악기가 들어오면 **총합이 올라가야 한다** — 자리를 비켜주는 건 *대역*(EQ)이지
*레벨*이 아니다. 기성곡의 "열린다"는 느낌은 리버브가 아니라 이 대비에서 나온다.

**11. "공간감이 없다"에 반사적으로 widener 를 걸지 않는다.** 먼저 잰다. 실측 사례는 Side −5 dB
(전 대역 고름) · 저역 −13.8 dB · 상관도 0.36 · 모노 손실 1.0 dB 로 **이미 교과서적으로 건강**했고,
넓혔으면 모노 호환만 깨졌을 것이다. 밋밋함의 정체는 좁아서가 아니라 **구간별 상관도가
0.29~0.44 에 고정**돼 폭조차 변하지 않아서였다. 답은 넓히는 게 아니라 *구간마다 다르게* 만드는
것이다 — verse 는 좁게, chorus 에서 연다 (절차 7 의 경계 오토메이션을 폭에도 적용).

## DAW 쪽에 요구할 것

**스템 추출** — 노멀라이즈 **끔**(켜면 측정이 무의미) · 이펙트 플러그인 우회 **해제** ·
볼륨/팬 오토메이션 **포함**(현재 밸런스 재현) · WAV 24bit · **바운스 종료 = 마지막 음 + 8초**.

**클리핑이 있으면** 전 채널 페이더를 **일괄 −6 dB** 하고 재추출. 밸런스는 그대로 유지되고
헤드룸만 생긴다.

**파일명으로 트랙을 식별하지 않는다.** 믹서 순서와 파일명 정렬이 달라서 실제로 페이더 값이
서로 뒤바뀌어 들어갔다. **재생 구간으로 식별**하게 표를 만들어 준다. 더블트랙 쌍은 **같은 값**을
줘서 뒤바뀌어도 무해하게 만든다.

**Logic 특이사항** — 채널 페이더 상한이 **+6 dB**다. 그 이상은 Gain 플러그인으로.
UI 가 한국어면 `logic-pro-mcp` 는 믹서·트랙을 **못 읽는다**(AXDescription 을 영어로 하드코딩,
실패 시 엉뚱한 AXOutline 을 반환). 오토메이션·플러그인 파라미터·버스 생성 API 도 없다.
**DAW MCP 로 믹스를 구성하려 들지 말 것.**

## 안 하는 것

- **내 귀 없이 "좋다/나쁘다"를 단정하지 않는다.** 측정은 문제를 *찾는* 도구지 취향을 정하는 도구가 아니다.
  밸런스·폭·라우드니스는 후보를 굽고 사람이 고른다.
- **사용자 체감이 측정과 어긋나면 측정을 의심하기 전에 무엇을 재고 있는지를 의심한다.**
  "중간에 베이스가 작다"는데 저역 에너지는 더 컸던 사례 — 부족한 건 에너지가 아니라 *악기*였고,
  EQ 로 만들 수 없는 것이었다. 이럴 땐 편곡 공백을 그대로 보고한다.
- **편곡을 대신 바꾸지 않는다.** 빈 구간을 채우는 건 연주의 몫이다. 공백을 지적하고 선택지를 준다.
- **DAW 프로젝트를 인덱스만 보고 조작하지 않는다.** 읽기가 안 되는 상태에서 쓰면 남의 트랙을 망친다.
