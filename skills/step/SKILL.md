`agentic-workflow` 스킬의 4~6단계(실행 → 검증 → 보고)를 **한 스텝에만** 적용한다.

`$ARGUMENTS` 가 비어 있으면 현재 Spec 의 다음 미완료 항목을 스텝으로 잡는다.

- 스텝 선언 · 검증 명령 · 수술적 변경 · 보고 형식은 스킬을 따른다
- 검증에 실패하면 출력과 함께 보고한다. **넘어가지 않는다**
- 해당 체크리스트 항목을 `[x]` 로 갱신한다. 구조 · 경로가 바뀌었으면 Spec 본문에도 반영한다
- 보고 후 **멈춘다** — 다음 스텝을 앞질러 실행하지 않고, 커밋도 하지 않는다
