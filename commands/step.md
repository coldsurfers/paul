description: Spec 체크리스트의 다음 스텝 하나를 실행하고 biome + type check 로 검증한 뒤 멈춘다.
---

`$ARGUMENTS` (비어 있으면 현재 Spec 의 다음 미완료 항목) 를 **한 스텝만** 실행한다.

## 순서

1. **스텝 선언**

```
STEP N — <무엇을>
검증: <어떻게 확인할지>
```

2. **구현** — 수술적으로. 모든 변경 라인이 이 스텝으로 직접 추적돼야 한다.
   - 인접 코드·주석·포매팅을 "개선" 하지 않는다
   - 무관한 데드 코드는 말만 하고 지우지 않는다
   - 내 변경 때문에 생긴 고아(미사용 import·변수·함수)만 정리한다

3. **검증**

```bash
pnpm biome check --write <변경한 파일들>
pnpm turbo check:type
```

실패하면 출력과 함께 실패를 보고한다. **넘어가지 않는다.**

4. **Spec 갱신** — 해당 체크리스트 항목을 `[x]` 로. 구조·경로가 바뀌었으면 Spec 본문에도 반영한다.

5. **보고 후 정지**

```
## 한 것
## 왜
## 다음 스텝 (제안)
```

**다음 스텝을 앞질러 실행하지 않는다.** 커밋도 하지 않는다 — 사용자가 명시적으로 요청할 때만.
